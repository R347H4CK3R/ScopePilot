# Privacy (development preview)
ScopePilot does not include analytics, ads, account registration, cloud storage, or a network research service. Program records and draft reports are stored locally in WebView storage. Clearing app data or uninstalling can remove them. Android platform backup is disabled; iOS device backups may include app data under the user's OS backup settings. Data is not additionally encrypted by ScopePilot.

Discovery refresh sends a read-only HTTPS request to raw.githubusercontent.com, which receives normal network metadata such as IP address and user agent. No credentials, notes, headers, reports, or program authorization are included. Retrieved candidates remain in session memory until the user manually adds a reviewed program. The app does not transmit research content automatically. Export opens the OS share sheet; destinations the user selects receive the shared content under their own policies. Opening official policy or directory links launches the system browser, where those sites may collect normal browsing data. No guarantee is made that a third-party policy URL remains unchanged or trustworthy.

Known authorization/cookie headers are redacted before report persistence. Notes, URLs, custom headers, and program data may still contain sensitive information. Review all content before saving or sharing. This document must be reviewed and hosted with the publisher's support/privacy contact before store submission.
